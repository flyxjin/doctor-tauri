# 中药材销售管理系统 - 批量导入操作指引

## 一、功能概述

批量导入功能支持通过CSV或Excel文件批量导入药材数据，适用于：
- 首次系统初始化时导入大量药材数据
- 定期更新药材信息和库存数据
- 从其他系统迁移数据

## 二、支持的文件格式

| 格式 | 扩展名 | 编码要求 | 说明 |
|-----|-------|---------|------|
| CSV | .csv | UTF-8 (推荐) 或 GBK | 通用格式，兼容性最好 |
| Excel | .xlsx | - | 需要安装openpyxl库 |

## 三、字段规范

### 3.1 字段列表

| 字段名 | 中文名 | 是否必填 | 数据类型 | 说明 |
|-------|-------|---------|---------|------|
| name | 药材名称 | **是** | 文本 | 唯一标识，重复时更新 |
| alias | 别名 | 否 | 文本 | 多个别名用顿号分隔 |
| category | 分类 | 否 | 文本 | 如：补虚药、清热药等 |
| nature | 药性 | 否 | 文本 | 如：寒、热、温、凉、平 |
| taste | 药味 | 否 | 文本 | 如：甘、苦、辛、酸、咸 |
| meridian | 归经 | 否 | 文本 | 如：归心、肝、脾经 |
| efficacy | 功效 | 否 | 文本 | 主要功效描述 |
| indications | 主治 | 否 | 文本 | 主治病症描述 |
| usage | 用法 | 否 | 文本 | 如：煎服、冲服 |
| dosage | 用量 | 否 | 文本 | 如：3-9g |
| contraindication | 禁忌 | 否 | 文本 | 使用禁忌说明 |
| notes | 备注 | 否 | 文本 | 其他备注信息 |
| quantity | 库存数量 | 否 | 数字 | 当前库存量 |
| unit | 单位 | 否 | 文本 | 默认为g |
| price | 单价 | 否 | 数字 | 单位：元 |
| min_stock | 最低库存 | 否 | 数字 | 库存预警阈值 |

### 3.2 字段映射示例

```
CSV文件表头示例：
name,alias,category,nature,taste,meridian,efficacy,indications,usage,dosage,contraindication,notes,quantity,unit,price,min_stock
```

## 四、数据验证规则

### 4.1 必填字段验证
- `name` 字段不能为空
- 空行将被自动跳过

### 4.2 数据类型验证
- 数值字段（quantity、price、min_stock）必须为有效数字
- 非数字内容将导致该字段使用默认值

### 4.3 重复数据处理
- 相同名称的药材将更新已有记录
- 更新时会同时更新库存信息

## 五、导入步骤

### 步骤1：准备数据文件
1. 点击"下载模板"获取标准模板
2. 按模板格式填写药材数据
3. 保存为CSV或Excel文件

### 步骤2：选择文件
1. 点击"选择文件"按钮
2. 选择准备好的数据文件
3. 系统自动解析并显示预览

### 步骤3：确认导入
1. 检查预览数据是否正确
2. 点击"开始导入"按钮
3. 确认导入提示

### 步骤4：查看结果
1. 查看导入进度条
2. 查看导入日志
3. 检查错误信息（如有）

## 六、常见问题解决方案

### Q1: 文件编码错误
**症状**: 打开CSV文件显示乱码

**解决方案**:
- 使用UTF-8编码保存CSV文件
- Excel导出CSV时选择"CSV UTF-8"格式
- 或使用记事本另存为UTF-8编码

### Q2: 药材名称重复
**症状**: 导入后药材数量少于预期

**解决方案**:
- 系统会自动更新同名药材
- 检查导入日志中的"更新"数量
- 这是正常行为，无需担心

### Q3: 数值字段导入失败
**症状**: 库存、价格等数值为0

**解决方案**:
- 确保数值字段只包含数字
- 不要包含单位（如"500g"应写为"500"）
- 不要使用中文数字

### Q4: Excel文件无法导入
**症状**: 选择.xlsx文件后无反应

**解决方案**:
- 确保已安装openpyxl库
- 或将Excel另存为CSV格式导入
- 安装命令: `pip install openpyxl`

### Q5: 导入中断
**症状**: 导入过程中断或卡住

**解决方案**:
- 点击"取消"按钮
- 检查数据文件是否有特殊字符
- 分批导入数据

## 七、模板下载

点击系统中的"下载模板"按钮可获取包含示例数据的标准模板。

模板包含两个示例药材：
1. 人参 - 补虚药代表
2. 黄芪 - 补气药代表

## 八、技术支持

如遇到其他问题，请检查：
1. 数据文件格式是否正确
2. 字段名称是否与规范一致
3. 数据内容是否包含特殊字符
