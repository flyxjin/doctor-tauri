
# 中药材数据导入功能模块使用说明

## 一、功能概述

本模块为中药材销售管理系统提供了完整的数据导入功能，支持从CSV、JSON等格式文件批量导入中药材数据，包含数据验证、清洗、标准化、事务处理、进度可视化等完整功能。

## 二、核心功能特性

### 1. 数据来源支持
- **CSV格式**：支持标准CSV文件导入
- **JSON格式**：支持JSON数组或包含data字段的JSON对象
- **自动识别**：根据文件扩展名自动识别格式

### 2. 数据验证与清洗
- **必填项检查**：药材名称为必填字段
- **数据格式验证**：
  - 药性验证：仅支持寒、热、温、凉、平
  - 药味验证：仅支持酸、苦、甘、辛、咸、淡、涩
- **数据清洗**：自动去除多余空格、统一格式

### 3. 数据标准化
- **名称标准化**：去除多余空格、统一格式
- **药性标准化**：支持"寒性"、"温性"等自动转换
- **药味标准化**：统一使用顿号分隔
- **分类标准化**：支持22个中药分类自动映射

### 4. 批量导入
- 支持单次导入1000+条数据
- 多线程处理，界面不卡顿
- 实时进度显示

### 5. 导入日志记录
- 详细记录每条数据的导入状态
- 记录成功、失败、跳过、警告状态
- 保留错误原因和原始数据
- 支持查看历史导入任务

### 6. 事务处理
- 整个导入过程使用数据库事务
- 出错时自动回滚，保证数据一致性
- 支持断点续传（通过checkpoint）

## 五、使用步骤

### 1. 准备数据文件
- 下载模板文件
- 按照模板格式填写数据
- 保存为CSV或JSON格式

### 2. 导入数据
1. 打开系统，点击左侧导航栏的"数据导入"
2. 点击"浏览..."按钮，选择准备好的数据文件
3. 选择导入选项（是否跳过已存在的药材）
4. 点击"开始导入"按钮
5. 等待导入完成，查看结果

### 3. 查看历史
1. 切换到"导入历史"标签页
2. 点击"刷新"按钮查看最新任务
3. 点击某个任务查看详细日志

## 六、核心API接口

### DataImporter类

```python
from data_importer import DataImporter

importer = DataImporter(db)

# 从CSV导入
result = importer.import_from_csv(
    file_path='data.csv',
    task_name='我的导入任务',
    progress_callback=progress_func,
    skip_existing=True
)

# 从JSON导入
result = importer.import_from_json(
    file_path='data.json',
    task_name='我的导入任务',
    progress_callback=progress_func,
    skip_existing=True
)
```

### Database类（新增方法）

```python
# 创建导入任务
task_id = db.create_import_task(task_name, source_type, file_path, total_count)

# 更新任务状态
db.update_import_task(task_id, processed_count, success_count, failed_count, status)

# 完成任务
db.complete_import_task(task_id, success_count, failed_count)

# 添加日志
db.add_import_log(task_id, row_number, medicine_name, status, error_message, data)

# 获取任务列表
tasks = db.get_import_tasks(limit=50)

# 获取任务日志
logs = db.get_import_logs(task_id, limit=1000)

# 事务操作
db.begin_transaction()
db.commit()
db.rollback()
```

## 八、注意事项

1. **文件编码**：CSV文件建议使用UTF-8-BOM编码，以确保中文正常显示
2. **数据唯一性**：药材名称必须唯一，重复的会被跳过或报错
3. **备份数据**：导入前建议先备份数据库文件
4. **分批导入**：数据量极大时（超过10000条），建议分批导入
5. **网络要求**：本功能完全离线，无需网络连接

## 九、故障排除

### 问题1：导入后中文乱码
**解决**：确保CSV文件使用UTF-8-BOM编码保存

### 问题2：提示"药材已存在"
**解决**：可以勾选"跳过已存在的药材"选项，或修改数据文件中的药材名称

### 问题3：导入过程中程序无响应
**解决**：导入在后台线程运行，界面会实时更新进度，请耐心等待
