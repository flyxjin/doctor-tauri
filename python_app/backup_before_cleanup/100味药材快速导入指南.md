## 🔧 方法二：Python脚本直接导入

如果需要更灵活的控制，可以创建一个简单的脚本：

### 创建导入脚本 `自定义导入.py`：

```python
import sys
import os
sys.path.insert(0, os.path.dirname(__file__))

from database import Database
from inventory_entry import InventoryEntrySystem

def main():
    print("开始导入...")
    
    db = Database()
    entry_system = InventoryEntrySystem(db)
    
    csv_file = "大药房库存录入模板_100味.csv"
    results = entry_system.batch_import_from_csv(csv_file)
    
    print(f"成功: {results['success']}, 失败: {results['failed']}")
    
    report = entry_system.generate_entry_report(results)
    print(report)
    
    db.close()

if __name__ == '__main__':
    main()
```

运行：
```powershell
python 自定义导入.py
```

## ⚠️ 常见问题及解决方法

### 问题1：找不到文件

**错误信息**：
```
错误: 找不到文件 d:\learn\DOCTOR\python_app\大药房库存录入模板_100味.csv
```

**解决方法**：
- 确认文件在正确的目录下
- 检查文件名是否正确（注意中文字符）
- 将文件复制到 `python_app` 目录

---

### 问题2：编码错误

**错误信息**：
```
UnicodeDecodeError: 'gbk' codec can't decode...
```

**解决方法**：
- 确保CSV文件使用UTF-8编码（推荐UTF-8 with BOM）
- 可以用记事本打开，另存为时选择"UTF-8"编码

---

### 问题3：数据格式错误

**错误信息**：
```
缺少必填字段: name
库存数量格式错误
采购日期格式错误，应为 YYYY-MM-DD
```

**解决方法**：
- 检查CSV文件，确保必填字段有值
- 确保日期格式正确（如 2025-01-15，不是 2025/1/15）
- 确保数量和价格是数字

---

### 问题4：药材已存在

**现象**：部分药材显示"更新"而非"新增"

**原因**：系统检测到同名药材已存在，会自动更新信息

**解决方法**：
- 这是正常行为，系统会合并库存数量
- 如需清空重新导入，可先备份数据库后删除 `medicine_system.db`

---

### 问题5：数据库锁定

**错误信息**：
```
database is locked
```

**解决方法**：
- 关闭其他正在使用数据库的程序（如主程序）
- 等待几秒钟后重试
- 检查是否有其他Python进程在运行

---

### 问题6：导入速度慢

**优化建议**：
- 这是正常现象，100条数据通常需要5-10秒
- 确保没有其他程序占用大量CPU
- 可以分批导入（但本工具已优化）

创建验证脚本 `验证导入.py`：

```python
from database import Database

db = Database()

print("=== 验证导入结果 ===\n")

med_count = db.fetchone("SELECT COUNT(*) FROM medicines")[0]
inv_count = db.fetchone("SELECT COUNT(*) FROM inventory")[0]

print(f"✓ 药材数量: {med_count}")
print(f"✓ 库存记录: {inv_count}")

if med_count &gt;= 100 and inv_count &gt;= 100:
    print("\n🎉 验证通过！数据导入成功！")
else:
    print("\n⚠️  数据可能不完整，请检查导入报告")

print("\n=== 前5味药材 ===")
medicines = db.fetchall("SELECT name, category, origin FROM medicines LIMIT 5")
for med in medicines:
    print(f"  - {med[0]} ({med[1]}) - {med[2]}")

db.close()
```

运行验证：
```powershell

```
