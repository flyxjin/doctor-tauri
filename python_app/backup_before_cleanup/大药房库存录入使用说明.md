
# 大药房中草药库存录入系统 - 使用说明

## 一、系统概述

本系统为大药房提供了完整的中草药库存信息录入功能，支持单条录入和批量导入，包含完整的数据校验、报告生成等功能。

### 核心功能
- **单条录入**：逐味药材录入详细信息
- **批量导入**：支持CSV格式批量导入
- **数据校验**：完整的字段完整性和格式验证
- **报告生成**：自动生成数据录入报告
- **库存管理**：完整的库存追踪功能

### 3.3 注意事项
1. **文件编码**：CSV文件必须使用UTF-8-BOM编码保存
2. **日期格式**：必须使用YYYY-MM-DD格式（如：2025-01-15）
3. **药材等级**：只能是：一等、二等、三等、统货、精选、特级
4. **质量状态**：只能是：合格、待检、不合格、过期
5. **药性**：只能是：寒、热、温、凉、平
6. **药味**：多个药味用顿号分隔，如：甘、微苦

## 四、数据校验规则

### 4.1 必填项检查
- 药材名称 (name)
- 库存数量 (quantity)
- 单价 (price)

### 4.2 格式检查
- 数量和价格必须为数字且不能为负数
- 日期格式必须为YYYY-MM-DD
- 药材等级必须在允许范围内
- 质量状态必须在允许范围内

### 4.3 一致性检查
- 药材名称唯一性检查
- 保质期必须晚于采购日期

## 五、操作流程

### 5.1 准备数据
1. 下载或打开 `大药房库存录入模板.csv`
2. 按照模板格式填写每味药材的信息
3. 确保必填字段都已填写
4. 检查日期格式是否正确

### 5.2 数据录入
方式一：使用库存录入系统（推荐）
```python
from database import Database
from inventory_entry import InventoryEntrySystem

db = Database()
entry_system = InventoryEntrySystem(db)

results = entry_system.batch_import_from_csv('大药房库存录入模板.csv')
report = entry_system.generate_entry_report(results)
print(report)
```

方式二：单条录入
```python
data = {
    'name': '人参',
    'quantity': '500',
    'price': '85',
    'origin': '吉林长白山',
    'grade': '一等',
    'purchase_date': '2025-01-15',
    'expiry_date': '2027-01-14',
    'supplier': '长白山人参种植合作社',
    'batch_number': 'CS-RS-2025-001',
    'storage_location': 'A区-01-01',
    'quality_status': '合格'
}

success, message, med_id = entry_system.add_inventory_item(data)
```

### 5.3 数据校验
系统会自动进行以下校验：
1. 字段完整性检查
2. 数据格式验证
3. 业务规则检查
4. 与实际库存的一致性核对

### 5.4 生成报告
录入完成后，系统会自动生成包含以下内容的报告：
- 报告生成时间
- 录入统计（总数、成功、失败）
- 错误详情（前20条）
- 录入耗时

## 八、常见问题

### Q1: 导入时提示"药材名称不能为空"
**A**: 检查CSV文件中name列是否有空值

### Q2: 日期格式错误怎么办
**A**: 确保日期使用YYYY-MM-DD格式，如2025-01-15

### Q3: 如何修改已录入的药材信息
**A**: 重新导入相同药材名称的数据，系统会自动更新

### Q4: 如何查看已录入的库存
**A**: 使用系统的药材管理和库存管理功能查看
