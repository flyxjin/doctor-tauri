# 页面标题栏设计规范

## 1. 设计概述

### 1.1 设计目标
为系统界面左上角内容区域设计专业的文字标识，提供清晰的页面导航信息，增强用户体验和品牌识别度。

### 1.2 设计原则
- **一致性**：与系统整体设计风格保持协调
- **可读性**：确保文字在不同屏幕尺寸下清晰可读
- **响应式**：字体大小随窗口尺寸自适应调整
- **简洁性**：信息层次分明，视觉简洁优雅

### 2.2 字体规范

| 元素 | 字体大小 | 字重 | 颜色 |

| 屏幕宽度 | base_size | 主标题 | 副标题 | 图标 |

| 1000-1400px | 14px | 21px | 13px | 31px |

### 2.4 间距规范

|------|------|

## 5. 响应式设计

### 5.1 字体缩放机制

标题栏组件继承系统的响应式字体管理器，通过以下机制实现自适应：

```python
def _apply_styles(self):
    base_size = self.font_manager.current_base_size
    title_size = int(base_size * 1.5)
    subtitle_size = int(base_size * 0.95)
    icon_size = int(base_size * 2.2)
```

### 5.2 窗口尺寸监听

- 窗口大小改变时自动更新字体
- 支持最大化/全屏状态切换
- 防抖处理避免频繁重绘

## 6. 组件使用说明

### 6.1 PageHeader 组件

**用途**：用于主窗口内容区域的页面标题显示

**基本用法**：
```python
from widgets.page_header import PageHeader

# 创建标题栏
header = PageHeader('medicine')

# 切换页面标题
header.set_page('prescription')

# 更新字体（响应窗口大小变化）
header.update_fonts()
```

### 6.2 CompactHeader 组件

**用途**：用于对话框或子页面的紧凑型标题

**基本用法**：
```python
from widgets.page_header import CompactHeader

# 创建紧凑标题栏
header = CompactHeader('批量导入', '支持CSV和Excel格式')

# 动态更新标题
header.set_title('导出数据', '导出为CSV文件')
```
