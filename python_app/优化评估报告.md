# 中药材销售管理系统 优化评估报告

> 版本：v4.2.0（2026-07-17）
> 状态：本文档随版本同步更新，记录优化项的实施状态与后续方向。

## 一、架构优化

### 已完成 ✅
- **分层架构合规改造**：所有 View 统一通过 Service 层访问数据，消除 dashboard/statistics/history/prescription_view 中 14 处直接 SQL 调用
- **新增 StatisticsRepository**：收纳仪表盘与销售统计的聚合查询，全走 SQLAlchemy ORM
- **新增 DashboardService / StatisticsService**：业务服务封装，View 不再直接访问 Repository
- **配伍禁忌规则外置**：27 对禁忌配对从硬编码迁移到 `core/data/compatibility_rules.json`，支持热更新（`reload_compatibility_rules()`）
- **缓存定向失效**：`MedicineCache._query_cache` 改为按药材 name/alias/category/nature 精准失效，替代全量 `clear()`，避免高频搜索时的缓存抖动
- **Dashboard widget 复用**：`_RevenueBar` 实例预创建并复用，零 widget 重建
- **HistoryView 分页**：新增分页 UI（每页 10/20/50/100 条），Repository 层 `find_all` 支持 offset 参数，新增 `count_all` 方法

### 后续方向
- 引入 Alembic 替代手写 `_migrate_schema`，获得版本化迁移
- 写操作全面切换到 SQLAlchemy ORM（阶段 2.4）
- 引入 Pydantic v2 替代 dataclass，获得运行时验证
