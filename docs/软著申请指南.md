### 主要功能和技术特点（申请表可整段复制）

> 本软件是一款面向中医诊所与中药房的桌面端开方销售管理软件，实现药材档案、批次库存、处方开立、销售统计的完整业务闭环。主要功能包括：488 味中药材档案管理；一药多批次库存管理与效期预警，按近效期优先（FEFO）跨批次自动出库；处方开立支持 169 张经典方剂模板套用、十八反十九畏配伍禁忌实时预警、患者过敏史冲突检测；处方删除按批次扣减明细精确回扣库存；销售统计与 CSV 批量导入导出；数据本地备份还原与操作日志留痕；基于 Gitee Release 的自动更新并附 SHA256 完整性校验。技术特点：采用 Tauri 2.x 框架（Rust 后端 + WebView 前端），安装包仅 3MB、启动秒开；SQLite WAL 模式加连接级 PRAGMA 调优，全部 SQL 参数化并配事务原子化与索引优化；前端 React 18 + TypeScript 严格模式 + Ant Design 5，服务端状态统一由 TanStack Query 管理并分级缓存；数据库结构由版本化迁移脚本管理，支持幂等升级。

## 三、其他材料

1. **登记申请表**：在中国版权保护中心线上系统（register.ccopyright.com.cn）在线填写并打印、签章；
2. **身份证明**：
   - 个人申请：身份证复印件（正反面，本人签字）；
   - 企业申请：营业执照复印件（加盖公章）；
3. 联系方式与邮寄地址信息。

## 四、办理流程

1. 注册并登录中国版权保护中心线上登记系统；
2. 选择「计算机软件著作权登记申请」，在线填写申请表（对照本文第一节预填）；
3. 上传 / 邮寄鉴别材料（源程序 PDF + 用户手册 PDF）与身份证明；
4. 受理后等待审查，一般 30~40 个工作日出结果（官方渠道，具体以当期公告为准）；
5. 审核通过后领取《计算机软件著作权登记证书》。

费用说明：软件著作权登记费已按国家规定停征（以 CPCC 当期收费公告为准）；如通过代理机构办理加急，费用与代理自行约定，与本指南无关。

## 五、注意事项

1. **版本号一致性**：申请表的版本号必须与鉴别材料页眉、软件"关于"弹窗中显示的版本完全一致（当前均为 V1.4.0；版本号在 `package.json` 修改后经 `npm run version:sync` 同步，重新生成鉴别材料即可保持一致）；
2. **重打包后再生成**：每次升版后先构建发行、再执行 `npm run copyright` 重新生成鉴别材料，保证材料对应拟登记版本；
3. **两版分别申请**：按既定策略，Python 版（V5.2.0）与 Tauri 版分别申请两个软著，两版代码完全不同，可最大化保护范围；本指南仅覆盖 Tauri 版；
4. **开发完成日期**：若拟登记 v1.4.0，完成日期以 v1.4.0 发布（CHANGELOG 记载 2026-09-24）为准，不要填晚于首次发表日的日期；
5. **源代码保密**：鉴别材料含完整业务实现，属内部材料，勿在登记完成前公开上传至网络。
