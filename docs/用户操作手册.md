## 1. 系统简介

中药材销售管理系统是一款面向中医诊所与中药房的桌面端开方与销售管理软件。系统覆盖"药材档案 → 库存批次 → 开方销售 → 统计复盘"的完整业务闭环，内置 488 味中药材数据库、169 张经典方剂模板、十八反十九畏配伍禁忌预警与患者过敏史冲突检测。

核心能力一览：

- **批次效期管理**：一药多批、近效期优先（FEFO）出库、效期预警
- **智能开方**：方剂模板一键套用、配伍禁忌实时预警、过敏史冲突检测、默认剂量解析
- **库存自动回扣**：删除处方按批次精确回扣库存，保障账实一致
- **数据安全**：本地数据库、每日启动自动备份、一键备份还原（SHA256 校验）、操作日志全程留痕
- **自动更新**：启动后台静默检查新版本，下载后校验完整性并引导安装

系统所有数据保存在本机（`%APPDATA%\com.medicine.system\medicine_system.db`），不经任何云端传输。

## 2. 安装与启动

### 2.1 安装包安装（推荐）

1. 获取安装包 `中药材销售管理系统_V1.4.0_x64-setup.exe`；
2. 双击运行，按向导点击「下一步」完成安装（需要管理员权限）；
3. 安装完成后，桌面与开始菜单出现「中药材销售管理系统」快捷方式；
4. 首次安装如出现 Windows SmartScreen「未知发布者」提示，点击「仍要运行」即可。

### 2.2 便携版

提供免安装的 `medicine-system.exe`，双击即可运行；数据同样保存在系统应用数据目录。适合 U 盘携带或无管理员权限的环境。

### 2.3 首次启动

首次启动系统自动完成数据库初始化，并内置 488 味药材种子数据，可直接开方销售。建议按"快速上手"流程先完成基础数据准备。

## 3. 界面总览与基本操作

### 3.1 界面布局

- **左侧边栏**：功能导航，分「业务」（开处方/客户管理/处方历史）与「数据」（药材管理/库存管理/销售统计/批量导入）两组，底部为「系统设置」；点击底部折叠按钮可收起为图标模式；
- **顶栏**：当前页面标题、日期、快捷键帮助（问号）、深浅主题切换（灯泡）；
- **主内容区**：各功能页面。

### 3.2 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + 1 ~ 9 | 按菜单顺序快速切换页面 |
| Ctrl + S | 保存处方（仅开处方页） |
| F1 | 打开/关闭帮助与关于弹窗 |

说明：开处方页已录入药材未保存时，使用 Ctrl+1~9 切换页面会弹出确认框，防止误触丢失处方内容。

### 3.3 界面主题

点击顶栏灯泡按钮在浅色（宣纸风）与深色（墨绿风）主题间切换，选择自动保存，重启后保持。

### 3.4 通用交互约定

- 表格双击行可打开详情（库存/处方/患者等）；
- 删除类操作均有红色二次确认；
- 查询失败时页面顶部出现错误提示条，可点击「重试」；
- 所有列表页右上角提供 CSV 导出，文件保存到系统「下载」目录。

折线图同时展示每日营收（红）与处方数（绿），鼠标悬停查看当日明细。

### 4.5 低库存预警与最近处方

- 左侧表格列出最紧缺的 20 种药材（当前库存 ≤ 最低库存阈值），点击行内「去入库」直接补货；

## 5. 药材管理

维护药材基础档案，是开方与库存的前提。

### 5.1 新增 / 编辑药材

点击「新增药材」打开表单：

| 字段 | 说明 |
|------|------|
| 名称 | 必填，如「人参」 |
| 别名 | 多个别名用逗号分隔，供搜索命中 |
| 分类 / 性 / 味 / 归经 | 药性信息，可从下拉选择或手填 |
| 功效 / 主治 / 用法 / 用量 / 禁忌 | 支持多行文本 |
| 备注 | 自由备注 |

编辑时名称不可重复；保存后立即在开处方与库存中生效。

### 5.2 检索与筛选

- 搜索框：按名称 / 别名 / 功效模糊匹配；
- 分类下拉与药性下拉可叠加过滤；
- 「库存量」列显示该药材跨批次合计，并按批次单位展示（g/包/盒等），点击表头可排序。

### 5.3 详情抽屉

点击「详情」查看药材完整档案，多行字段完整展开显示。

### 5.4 删除药材

删除前系统弹出确认框；删除将级联清除该药材全部库存批次与变更历史，不可恢复，请谨慎操作。

## 6. 库存管理

以"批次"为最小管理单位，支持效期与追溯。

### 6.1 批次与效期概念

同一药材可有多个批次（不同进货时间 / 价格 / 效期）。每条批次记录：批次号、生产日期、效期、数量、单价、最低库存。效期用于自动排序出库与到期预警。

### 6.2 入库

点击行内「入库」打开弹窗：

1. 操作类型选「入库」；
2. 录入数量（必须大于 0）；
3. 批次号：填入已有批次号则合并累加数量，留空则自动生成新批次；
4. 生产日期 / 效期：格式 `YYYY-MM-DD`（如 2027-06-01），格式错误会被拒绝；
5. 填写操作人与备注后确认。

说明：向已存在批次合并入库时，重新填写的效期/生产日期会覆盖旧值，未填项保持不变。

### 6.3 出库（FEFO 自动跨批次）

操作类型选「出库」后，系统按**近效期优先（FEFO）**自动跨批次扣减：先扣效期最近的批次，扣完自动切换到下一批次；无效期的批次最后扣减。库存不足时给出明确缺口提示，不做部分扣减。

### 6.4 库存调整（盘点）

点击「调整」将批次数量设置为实际盘点值，差值自动记入变更历史，备注建议填写盘点单号。

### 6.5 效期预警与低库存

- 页面顶部横幅展示 30 天内到期或已过期的批次（点击标签可定位）；
- 「低库存」「零库存」「近效期」三个标签页一键过滤；
- 低库存行橙色背景、零库存行红色背景高亮。

### 6.6 变更历史

点击「历史」查看该药材全部入库 / 出库 / 退库 / 调整记录，含批次、单价、金额、操作人。

## 7. 开处方

核心业务页面，左右分栏：左侧检索选择药材，右侧录入处方信息。

### 7.1 患者信息

- 在「患者姓名」输入框输入姓名，系统自动联想已有患者并回填年龄 / 性别 / 过敏史；
- 也可直接输入新姓名现场建档（建议先到「客户管理」建档，便于复诊追溯）；
- 患者存在过敏史时页面顶部出现黄色预警条：已录入药材命中过敏原时会明确标红提示。

### 7.2 添加药材

左侧搜索药材后点击加入处方；系统自动带出单价、单位，并从「用量」字段解析默认剂量（如 `3-9g` 解析为中间值）。已存在的药材不可重复添加。每行可修改数量，删除按钮可移除该味药；金额 = 数量 × 单价，自动合计。

### 7.3 配伍禁忌预警

药材 ≥ 2 味时系统自动进行十八反 / 十九畏检查：出现禁忌组合时页面顶部弹出黄 / 红色警示，列出冲突药对与依据，供医师复核调整。

### 7.4 使用方剂模板

点击「方剂模板」打开模板选择器（169 张经典方剂，支持按名称 / 主治搜索）。选择模板后自动填入诊断并按模板组成逐味匹配药材加入处方；数据库中缺失的药材会列出"未找到"清单供人工处理。

### 7.5 保存处方

- 开方日期默认当天，可修改（仅到日期）；
- 「开方人」建议填写接诊医师；
- 点击「保存处方（Ctrl+S）」或按钮保存，成功后提示处方编号，并出现「打印刚才的处方」按钮。

保存时系统自动扣减库存：按 FEFO 规则逐批次扣减，并在处方内记录每个批次的扣减明细（删除处方时按此精确回扣）。

### 7.6 未保存保护

处方中已有药材但未保存时，通过快捷键或导航切换页面会弹出确认框：确认「离开」将丢失未保存内容，选「留在此页」继续编辑。

### 7.7 打印

保存成功后点击「打印刚才的处方」，系统生成标准中药处方笺（含患者信息、诊断、药材明细、合计）并发送到系统打印对话框。

## 8. 处方历史

查询与管理全部历史处方。

### 8.1 检索与筛选

- 关键字：按患者姓名或诊断模糊搜索；
- 日期快捷预设：今天 / 近 7 天 / 本月 / 近 3 月，也可用日期范围选择器自定义；
- 顶部统计（处方数 / 总味数 / 总金额）随筛选结果实时更新；
- 单次查询最多返回 500 条，达到上限时页面会提示，请缩小日期范围查询更早记录。

### 8.2 详情与操作

点击「详情」或双击行打开抽屉，展示处方全部明细与合计。行内操作：

- **打印**：发送处方笺到系统打印对话框；
- **导出PDF**：在打印对话框选择「Microsoft Print to PDF」保存为 PDF 文件；
- **复制**：将整张处方复制到开处方页（复诊"再来一剂"场景，可增删后另存）；
- **删除**：二次确认后删除处方，**系统按当初扣减的批次精确回扣库存**，并记录退库历史。

### 8.3 CSV 导出

右上角「导出 CSV」导出当前筛选结果的全部字段，可用于对外报送或备份。

## 9. 客户管理

患者档案管理与复诊支撑。

### 9.1 建档与编辑

点击「新增患者」录入：姓名（必填）、性别、年龄、电话、地址、**过敏史**、既往病史、备注。过敏史是开方预警的依据，请务必如实填写。

### 9.2 患者详情

点击「详情」打开抽屉：

- 档案完整信息；
- 该患者的全部历史处方（双击可展开明细）；
- 消费统计：处方总数、累计金额、首诊与末诊日期。

### 9.3 复诊开方

在患者详情的历史处方中选择一张，点击「复制到处方」即可带出整张处方到开处方页，调整后保存。

### 9.4 删除保护

存在处方记录的患者无法删除（系统校验并提示），防止历史数据脱钩。

### 9.5 导出

「导出 CSV」导出患者档案（含过敏史），便于纸质备份或外部统计。

## 11. 批量导入与导出

面向存量数据迁移与批量维护。

### 11.1 下载模板

点击「下载导入模板」获取标准 CSV 模板（含 2 条示例数据）。列依次为：名称、别名、分类、性、味、归经、功效、主治、用法、用量、禁忌、备注、数量、单位、单价、最低库存。

### 11.2 导入流程

1. 在 Excel 中按模板整理数据——可直接选择 `.xlsx` 文件，或另存为 CSV（UTF-8 编码）；
2. 点击「选择文件」载入，系统解析后预览全部记录，问题行标红提示；
3. 确认无误后点击「开始导入」，完成后显示新增 / 更新 / 失败数量与逐行错误信息。

### 11.3 导入规则

- 同名药材视为更新：更新其档案字段，**库存以新批次追加**（不覆盖原有批次）；
- 数量为 0 或空的记录仅更新药材档案，不创建库存批次；
- 单行失败不影响其他行，错误明细在结果中逐条列出；
- 功效等字段支持引号内换行（从本系统导出的 CSV 可直接回导）。

### 11.4 导出全量药材

设置页「导出全量药材 CSV」导出全部药材完整字段，可直接作为外部备份或再次导入的数据源。

## 12. 系统设置

包含版本更新、数据导入导出、备份还原与操作日志。

### 12.1 版本信息与自动更新

- 「当前版本」显示本机版本号；点击「检查更新」查询 Gitee 最新 Release；
- 启动应用时系统后台静默检查更新，发现新版本自动下载（显示进度），下载完成后弹窗提示「立即更新」，确认后静默安装并重启；
- 下载完成后进行 SHA256 完整性校验，校验失败的安装包自动删除，杜绝安装被篡改或损坏的安装包；
- 下载中可离开设置页，完成后回到页面仍可看到安装入口。

### 12.2 数据备份与还原

- **创建备份**：点击「立即创建备份」，系统对数据库做一致性快照并生成 SHA256 校验值，备份文件保存在 `backups/` 子目录；
- **自动每日备份**：每天首次启动时，若当天尚无任何备份（手动或自动），系统自动创建一份自动备份并仅保留最近 14 份（手动备份永不清理）；
- **备份提醒**：超过 7 天未备份（或从未备份）时，启动应用会弹窗提醒，点击「前往备份」直达；
- **还原备份**：点击「还原」并确认后，当前数据库被备份文件覆盖（还原前请先创建新备份）；系统还原后自动完成数据库结构升级并刷新应用；
- **删除备份**：仅允许删除 backups 目录内的备份文件。

### 12.3 操作日志

记录全部关键操作（建档 / 修改 / 删除 / 出入库 / 导入 / 备份 / 还原），支持按操作类型与日期范围筛选，最近 100 条内可翻页查看，用于追溯与对账。

## 13. 常见问题（FAQ）

**Q1：启动白屏？**
确认系统已安装 WebView2 Runtime（Windows 11 自带，Windows 10 需从微软官网安装），并重新启动程序。

**Q2：数据库文件在哪里？能否直接拷贝迁移？**
位于 `%APPDATA%\com.medicine.system\medicine_system.db`。整机迁移建议使用「系统设置 → 备份 / 还原」而非直接拷贝文件，可保证数据一致性。

**Q3：出库提示库存不足？**
出库按近效期优先跨批次自动扣减，提示中的"缺口"为全部批次合计后仍缺少的数量，请先入库补货。

**Q4：自动更新下载失败？**
检查网络后到「系统设置」重新下载；Release 页面须同时包含安装包与 `.sha256` 校验文件，缺失时系统跳过哈希校验（仅校验文件大小）。

**Q5：误删了处方，库存怎么办？**
删除处方时系统自动按原批次回扣库存并写入退库历史，无需手工修正。

**Q6：不安装软件能否预览界面？**
开发者在项目目录运行 `npm run dev` 后，用浏览器打开 http://localhost:1420 即进入演示模式（内置拟真数据，仅内存不落盘）。

**Q7：如何核对操作记录？**
「系统设置 → 操作日志」支持按操作类型（建档 / 修改 / 删除 / 库存 / 导入）与日期范围筛选。
